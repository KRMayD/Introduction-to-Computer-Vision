2026-11-05에 기존 Python 3.10.20 환경에서 확인했습니다. 전체 CIFAR-10 실험은 다시 실행하지 않았습니다.

| 공통 수치 구현 | 데이터 로더·세 투표 함수·ExactKNN·평가 함수의 AST가 원본과 동일 |

단위 테스트는 공유 GPU를 사용하지 않도록 `CUDA_VISIBLE_DEVICES=''`로 제한한 CPU 환경에서 실행했습니다. 독립 거리·분류기와의 비교, 동률·거리 0 처리, 실제 L2 거리 가중치, k=101까지의 투표를 확인했습니다.

재확인 명령은 [상위 README](../README.md#표-생성과-검증)에 있습니다. 이 기록은 정리 직후의 검증이며, 이후 코드를 수정하면 다시 검증해야 합니다.
