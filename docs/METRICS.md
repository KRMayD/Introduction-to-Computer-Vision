# 평가 지표

Accuracy는 전체 예측에서 계산합니다. Precision·Recall·F1은 각 클래스를 하나의 양성 클래스로 간주해 계산한 뒤, 10개 클래스를 동일 비중으로 평균하는 **Macro 평균**을 사용합니다. 0으로 나누는 경우 해당 지표는 0으로 처리했습니다.

| 지표 | 계산 | 의미 |
| --- | --- | --- |
| Accuracy | 전체 정답 수 / 전체 이미지 수 | 전체에서 얼마나 맞혔는가 |
| 클래스별 Precision | TP / (TP + FP) | 해당 클래스라고 예측한 것 중 얼마나 맞았는가 |
| 클래스별 Recall | TP / (TP + FN) | 실제 해당 클래스 중 얼마나 찾아냈는가 |
| 클래스별 F1 | 2TP / (2TP + FP + FN) | Precision과 Recall을 함께 고려한 조화평균 |

- TP: 실제 해당 클래스를 해당 클래스로 예측한 수.
- FP: 다른 클래스를 해당 클래스로 잘못 예측한 수.
- FN: 실제 해당 클래스를 다른 클래스로 잘못 예측한 수.

## Macro 평균

```text
Macro Precision = (P_0 + ... + P_9) / 10
Macro Recall    = (R_0 + ... + R_9) / 10
Macro F1        = (F1_0 + ... + F1_9) / 10
```

Macro F1은 클래스별 F1을 먼저 계산하고 평균합니다. 평균 Precision과 평균 Recall에 F1 공식을 직접 적용한 값과 다를 수 있습니다.

이번 검증·테스트 데이터는 클래스별 이미지 수가 동일하므로 Accuracy와 Macro Recall이 같습니다. 클래스별 이미지 수가 다르면 두 값은 달라질 수 있습니다.

## 실제 결과 예시

다수결 + 최근접 동률 해결의 Manhattan, k=5 모델은 테스트 10,000장 중 3,921장을 맞혔으므로 Accuracy는 **39.21%**입니다.

이 모델이 트럭으로 예측한 409장 중 실제 트럭은 288장이었습니다. 따라서 트럭 Precision은 **288/409 = 70.42%**입니다. 실제 트럭 1,000장 중 288장을 찾았으므로 Recall은 **28.80%**, F1은 **40.88%**입니다.

전체 Macro Precision·Recall·F1은 각각 **45.60%, 39.21%, 38.90%**입니다. 원자료는 [클래스별 결과](../results/04_k101/class_results.md)와 [혼동행렬](../results/04_k101/confusion_matrices.md)에 있습니다.

## CV 평균·표준편차와 OOF 지표

`cv_summary.csv`의 `*_mean`과 `*_std`는 5개 fold에서 계산한 지표의 평균과 표본 표준편차(`ddof=1`)입니다. 표준편차는 fold 간 변동을 나타내며 신뢰구간이 아닙니다.

`*_oof`는 각 이미지의 검증 예측을 모아 전체 50,000장에 대해 한 번 계산한 값입니다. Macro Precision과 Macro F1은 비선형 계산이므로, 통합 OOF 지표와 fold별 지표의 평균이 다를 수 있습니다. GitHub CV 표에는 `*_mean ± *_std`를 사용했습니다.

CSV에는 0~1 단위의 원본 수치를 보존하고, 문서와 그래프에는 100을 곱한 % 단위를 표시합니다. 정확도의 차이를 설명할 때는 %p를 사용합니다.
