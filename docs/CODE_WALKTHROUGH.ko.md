# 핵심 실행 코드 읽는 순서

이 문서는 한글 주석을 추가한 실행 코드의 연결 관계를 설명합니다. 주석을 추가하면서 계산식·실험 설정·실행 로직은 변경하지 않았습니다.

## 파일별 역할

| 파일 | 먼저 볼 부분 | 역할 |
| --- | --- | --- |
| [core.py](../knn_cifar10/core.py) | `ExactKNN`, 세 투표 함수, `evaluate()` | 데이터 읽기, 거리 계산, 이웃 탐색, 투표, 평가 지표 |
| [voting.py](../knn_cifar10/voting.py) | `run()` | 투표 방식·거리·k별 5-fold 검증, 모델 선택, 최종 테스트 |
| [tie_analysis.py](../knn_cifar10/tie_analysis.py) | `main()` | 같은 이웃에서 동률 해결 규칙만 바꿔 빈도와 성능 변화 분석 |
| [_runner.py](../experiments/_runner.py) | `run()` | 생략된 실행 옵션에 기본값을 채운 뒤 공통 모듈 호출 |
| [04_k101/run.py](../experiments/04_k101/run.py) | 마지막 `run(...)` | 최근접 동률 해결과 k=101 탐색을 기본 설정으로 전달 |

## k=101 실험의 호출 흐름

```text
experiments/04_k101/run.py
  └─ experiments/_runner.py: run()
       └─ knn_cifar10/voting.py: main()
            └─ run()
                 ├─ core.load_cifar10(): 전체 데이터 읽기
                 ├─ 5개 fold에서 core.ExactKNN.fit() / neighbor_labels()
                 ├─ all_predictions() → core.nearest_tie_predictions()
                 ├─ core.evaluate(): fold별 4개 지표 계산
                 ├─ CV 평균 정확도로 거리·k 선택
                 └─ 학습 50,000장 전체 참조 → 공식 테스트 10,000장 평가
```

01은 `core.py`의 `run()`으로 기본 실험을 수행합니다. 02는 `tie_analysis.py`의 `main()`으로 CV 동률을 분석합니다. 03은 04와 같은 `voting.py` 실행부에서 세 투표 방식을 모두 비교합니다.

## 1. 데이터와 배열

- 학습 이미지 `x`: `(50000, 3072)`, 정답 `y`: `(50000,)`입니다.
- 한 fold에서는 40,000장을 학습 참조 데이터로 저장하고 나머지 10,000장을 검증합니다.
- `labels[i, j]`는 i번째 질의 이미지에서 j번째로 가까운 학습 이미지의 클래스입니다.
- `votes[i, c]`는 i번째 질의에서 클래스 c가 받은 표 또는 가중치 합입니다.
- OOF 배열은 각 이미지가 검증 대상으로 사용된 fold에서 받은 예측을 원래 인덱스 위치에 저장합니다.

KNN의 `fit()`은 신경망 파라미터를 최적화하지 않습니다. 학습 이미지·정답과 거리 계산에 필요한 벡터 길이를 보관합니다.

## 2. 거리 계산과 이웃 선택

`ExactKNN.neighbor_labels()`는 질의 이미지를 배치로 나누어 학습 이미지 전체와의 거리를 계산합니다.

| 거리 | 계산 | 코드의 처리 |
| --- | --- | --- |
| Euclidean | `sqrt(sum((q - x)^2))` | 내적 공식을 이용해 제곱 거리를 계산하고 정렬합니다. 가중 투표에 반환할 때 실제 거리로 변환합니다. |
| Manhattan | `sum(abs(q - x))` | 모든 픽셀 차이의 절댓값을 합합니다. |
| Cosine | `1 - dot(q, x) / (norm(q) * norm(x))` | 내적과 벡터 길이로 방향 차이를 계산합니다. |

정렬된 이웃 중 최대 k개를 한 번 구하고, 작은 k에서는 앞부분을 재사용합니다. 이웃 간 거리가 같으면 안정 정렬로 학습 인덱스 순서를 유지합니다.

## 3. 세 가지 투표 함수

| 함수 | 표 계산 | 동률 처리 |
| --- | --- | --- |
| `majority_predictions()` | 모든 이웃이 1표 | 가장 작은 클래스 번호 선택 |
| `nearest_tie_predictions()` | 모든 이웃이 1표 | 최다 득표 클래스들에 속한 이웃 중 가장 가까운 이웃의 클래스 선택 |
| `distance_weighted_predictions()` | 실제 거리의 역수 `1/d`를 합산 | 가중치 합의 동률 후보 중 가장 가까운 이웃의 클래스 선택 |

예를 들어 거리순 이웃이 `새, 자동차, 비행기, 자동차, 비행기`라면 자동차와 비행기가 2표씩입니다. 기본 다수결은 번호가 작은 비행기를 선택하고, 최근접 동률 해결은 자동차를 선택합니다. 가장 가까운 새는 최다 득표 후보에 포함되지 않습니다.

거리 가중 투표에서는 가까운 새가 큰 가중치를 받아 선택될 수도 있습니다. 거리 0인 이웃이 있으면 그 이웃들만 동일한 가중치로 투표합니다.

## 4. 검증과 모델 선택

`voting.run()`은 기본 실험의 데이터 해시와 fold를 대조한 다음 같은 조건으로 실험합니다. 한 fold에서 찾은 이웃을 여러 투표 방식·k에 공유합니다.

1. 각 설정에서 5개 fold의 정확도·Macro 정밀도·Macro 재현율·Macro F1을 계산합니다.
2. 5개 값의 평균과 표본 표준편차(`ddof=1`)를 기록합니다.
3. 평균 CV 정확도가 가장 높은 거리·k를 선택합니다. 동률이면 작은 k, 거리 이름 순서입니다.
4. 선택 결과를 저장한 뒤 학습 50,000장 전체로 공식 테스트를 평가합니다.

통합 OOF 지표도 별도로 저장합니다. Macro 정밀도·F1은 비선형 계산이므로 통합 OOF 점수와 fold별 점수의 평균이 다를 수 있습니다.

## 5. 저장되는 결과

- `cv_folds.csv`: 각 fold의 개별 평가 지표.
- `cv_summary.csv`: 설정별 CV 평균·표준편차와 통합 OOF 지표.
- `test_results.csv`: 거리별 CV 최적 설정의 공식 테스트 결과.
- `classification_report.csv`, `confusion_*.csv`: 최종 모델의 클래스별 지표와 혼동행렬.
- `metadata.json`: 입력 데이터 해시, 설정, 환경, 모델 선택 기록.
- `predictions.npz`, 이웃 NPZ: 예측 재현과 추가 분석에 사용하는 로컬 캐시이며 Git 업로드에서는 제외합니다.

실행 명령은 [한국어 README](../README.md#실험-재현) 또는 [English README](../README.en.md#reproducing-the-experiments)에 있습니다. 코드만 읽으려면 실험을 실행할 필요가 없습니다.
